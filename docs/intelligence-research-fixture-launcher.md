# INT-18H.3c.2a — Controlador de lanzamiento fixture (sin despliegue)

Contrato Python sin handler AWS. Deshabilitado por defecto. La configuración debe provenir de un despliegue revisado, nunca de parámetros públicos. Valida región, cuenta, familia fixture y revisión, subnet y SG explícitos; sólo RunTask FARGATE count=1, sin IP pública, ECS Exec deshabilitado, overrides de run/vencimiento en worker y coordinator y tags exactos. No valida que los IDs de red correspondan a una VPC privada: eso queda para la integración de infraestructura. El token de idempotencia no habilita reintentos.

Una tabla separada (pk/sk) reservada exclusivamente al controlador registra de forma transaccional ACTIVE y RUN# antes de llamar ECS. El slot único evita concurrencia y no tiene TTL ni desbloqueo automático; incluso ante error incierto o crash queda cerrado. No se puede reutilizar un run. La escritura posterior enlaza el ARN de tarea retornado a la autorización original; el watchdog sólo debe aceptar la vinculación desde esta tabla confiable, y verificar DescribeTasks. La tarea no debe tener permiso de escritura o lectura de esta tabla. No confundirla con el ledger de páginas.

Limitaciones deliberadas: aún no hay Lambda, IAM, tabla desplegada, programación, reconciliación de respuestas RunTask ambiguas, liberación supervisada del slot ni watchdog operativo. Una tarea puede arrancar antes de que su ARN quede persistido; si la persistencia falla, se necesita reconciliar con startedBy/clientToken y confirmar la identidad sin relanzar. No activar hasta tener protección externa de vencimiento incluso ante este fallo. Configurar SDK con total_max_attempts=1, sin endpoints arbitrarios. No se permiten credenciales reales ni llamadas al proveedor. La prueba usa clientes falsos y no demuestra permisos AWS.
