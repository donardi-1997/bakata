# INT-18H.3c.2c — Red y autenticación de proxy sintético

La opción EnableProxyFixture es false por defecto y exige persistencia, red fixture y los IDs revisados de prefix lists regionales de S3 y DynamoDB. Añade dos subredes privadas con una tabla de rutas sin Internet Gateway, NAT, peering ni salida IPv6. Los endpoints gateway se asocian a esa tabla sólo bajo la condición. El worker usa un SG nuevo con salida TLS a SG de endpoints AWS, prefix lists S3/DynamoDB y TCP 8443 al SG del proxy. El proxy sólo tiene salida a endpoints AWS y prefix list S3 para futuro pull de imagen/logs; recibe 8443 exclusivamente del SG worker. No asignar el SG legacy al ensayo del proxy. DNS de VPC y servicios de metadatos no son bloqueados por SG; esto no es una garantía contra exfiltración por un contenedor comprometido. Verificar prefix lists, reglas efectivas, rutas y permisos en AWS antes de ejecutar.

El runtime del proxy exige flag sintético, bind privado, CA, certificado y clave de servidor montados y huella SHA256 exacta del certificado cliente; TLS 1.2+ y validación mTLS antes del parser CONNECT, sin enviar credenciales del proveedor. El modo ejecutable sólo utiliza resolver inyectado y upstream loopback con respuesta fija bakata-fixture-ok; jamás resuelve ni marca Dropi. La dirección pública sentinel 8.8.8.8 se pasa al predicado puro, no se conecta. El cliente debe verificar nombre y CA del servidor. Las pruebas de TLS usan certificados efímeros de OpenSSL en loopback, no secretos ni red externa. El relay anterior sigue siendo un contrato de biblioteca; no habilitar salida real.

Pendiente: certs efímeros por run y entrega segura fuera de logs/IPC, imagen por digest, definición de tarea proxy independiente sin task role, controlador que autorice ambos ARN y los detenga, integración del cliente WordPress con TLS al proxy, ensayo real de aislamiento y TLS extremo a extremo del proveedor, endpoint Secrets Manager revisado, reconciliación de fallos. Los endpoints y subredes no lanzan nada. No hay NAT, recursos comerciales, control presupuestario ni llamadas proveedor. La red real con egress sigue fuera del alcance.
