# Roadmap

## Sprint 01 — Foundation
- [x] Repositorio y documentación inicial.
- [x] Compose, script de instalación, tema y plugin base.
- [x] Workflow de validación y smoke test.
- [ ] Ejecutar CI y verificar instalación limpia.

- [ ] Identidad de marca y diseño móvil.

## Sprint 03 — Operación
- [x] Evaluación pública inicial de proveedores (ADR 001, propuesta Dropi).
- [ ] Confirmar proveedor, contrato API autorizado y sandbox; validar costos, inventario, entrega y devoluciones según [puertas G0–G6](provider-evaluation.md).

- [ ] Configurar pagos de prueba y flujo de pedidos y despacho.
- [ ] Validar políticas, datos personales e impuestos aplicables.

## Sprint 04 — Lanzamiento
- [ ] Staging y pruebas extremo a extremo.
- [ ] Producción segura, dominio, analítica y monitorización.
- [ ] Lanzamiento controlado con catálogo pequeño.
