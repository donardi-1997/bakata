# Cabecera y tipografías locales

La cabecera usa un shortcode registrado en el tema, renderizado en el servidor desde la parte de plantilla nativa header. Sin JS adicional. El editor muestra el shortcode; la vista pública renderiza el componente. Menú móvil con details/summary, búsqueda GET de productos, logo oficial, enlaces a tienda, cuenta y carrito según las páginas reales de WooCommerce. No se muestran contadores de carrito ni categorías/promociones ficticias. La barra superior usa el tagline, no promesas de envíos o pagos. El favicon SVG se usa solo cuando WordPress no tiene un icono configurado.

Fuentes OFL 1.1 de los repositorios originales Tokotype (commit 18d1cd2f7ea10481919d2f05c1f7064b7307fc26) y rsms/inter (v4.1). Licencias versionadas en assets/fonts. Los WOFF2 se provisionan con bash scripts/install-fonts.sh, verificados por blob Git fijado. No se solicitan fuentes a terceros desde el navegador. Los binarios se excluyen de Git; bootstrap instala las fuentes. En servidores existentes ejecutar el instalador como propietario del checkout antes de activar la revisión; si se modifica el manifiesto de fuentes en futuras entregas, repetir este paso antes del merge. No cambiar el wrapper de CD automáticamente. Si falla la descarga, el instalador termina con error; el navegador conserva fallback del sistema. Inter incluye itálica; Jakarta se usa en titulares normales.

Validar con navegador real: 320/375/768/1024/1440 px, teclado y foco, zoom 200%, menú nativo, búsqueda con consulta, enlaces y carga de fuentes. CI verifica el HTML público y el hash de una fuente, no certifica accesibilidad ni diseño visual.
